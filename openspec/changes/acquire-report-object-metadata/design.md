# Design

Native 8.3.27.2342 Designer XML and CF exported from the own open-bsl report control establish report class 19, distinct Object and Manager identities, and separate report collections. Reuse existing attribute/type and section projection only after checking their measured wrappers. Unknown, incomplete or duplicate collections remain None. Native original UNF resources provide a second case. Version remains unchanged pending user assignment.

## Measured representation

Native report class 19 has 18 members. Object identity is at index 1; Manager identity is at index 12. Report attribute, section and section-column collection identifiers differ from the processor. Their measured wrapper/body shapes agree, so section validation is shared, while owner validation and collection identities remain separate. The original UNF report has the same shape and checked empty collections. The existing extension restructure path does not acquire processor composition either; reports retain the same uncertainty rather than inventing complete extension composition.
