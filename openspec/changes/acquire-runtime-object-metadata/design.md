# Design
Use existing nested descriptors and member decoders. New owner collections are independently validated in native configuration order; missing, duplicate, malformed or unmeasured members invalidate the whole corresponding collection. Native XML and compiler-produced Config pairs establish layout, never BSL behavior or physical SQL tables. Number settings and standard-attribute policies use explicit business-process public types while sharing validated internal routines. Existing route-point acquisition remains unchanged. Unknown kinds and layouts stay None. Existing acquisition retains descriptors, so no independent database or SQL implementation is introduced.
