# Design

Use the existing parsed batch and code generator twice: the ordinary data branch uses current restricted decisions; the witness branch uses complementary decisions. The witness preserves the full dimension grain: removing unused dimensions would turn an empty resource-only aggregate into a synthetic NULL row and incorrectly report forbidden data. Combine them into one SQL statement with a Boolean service marker: ordinary rows false when the witness CTE is empty, a NULL-payload witness true when any forbidden balance exists. One statement observes one READ COMMITTED snapshot; no transaction API change, independent connection, or second SQL execution is needed. The principal, access decisions, separation, query and session parameter bindings remain supplied by the host.

Limit the opt-in ordinary path to PostgreSQL, one accumulation Balance source, direct own-field projections, no outer filter, ordering, joins, aggregate projections, unions, temporary placements or totals. The optional Balance dimension condition is a simple equality to a bound parameter or literal; no explicit period is supported. Restriction conditions are a simple own dimension equality to a literal/session parameter, optionally prefixed WHERE. Other forms fail with a Restriction diagnostic. Restriction NULL evaluates as not permitted. No claim is made about arbitrary balance grouping, joins, batches or aggregate authorization. ALLOWED retains its previous filtered compilation.

`forbidden_row_column` is appended to columns and service_columns; existing logical projection indices remain unchanged. A host must validate the Boolean marker for every row before logical materialization, deferred presentations, or exposing any values. Any true marker is an access error; a missing or malformed marker is an execution-contract error. Witness payload NULLs must never reach a logical decoder.

The original compiler behavior remains default for compatibility. Callers needing native ordinary behavior must explicitly enable this contract in a Restricted prepared compilation; the option does not weaken the restriction mode.
