# Design

Use the existing Config descriptor dimension/resource GUID collections and nonempty recognized declared types to prove membership. Require a native owner descriptor with both collections and register kind Balance. Authorize only own metadata GUID fields, not standard fields, arbitrary attributes or tabular sections. Existing exact member Read refusals and ambiguous paths remain conservative refusals; View is never renamed Read.

Object Read remains a prerequisite in each granting role. The existing user_decisions/read_access/compiler path retains RLS and combines granting roles with OR. Field authorization alone is not authorization to execute unrestricted SQL.

Evidence is copied verbatim from open-bsl/docs/research/fixtures/accumulation-field-access, including native Designer XML, completed receipts and provenance. Owner Read refusal rejects even ALLOWED queries. Restricted ordinary reads error; ALLOWED filters. Native direct-manager semantics are evidence for the consumer, not a new SDK manager API. Incomplete timeout receipts prove no completed manager result.

Turnovers registers have no independent permission measurement in this evidence set and remain unsupported by the new native mapping. Ordinary-query RLS error enforcement requires an execution guard not provided by the current compiler and is explicitly outside this field-mapping change; see docs/accumulation-field-access-0910.md.
