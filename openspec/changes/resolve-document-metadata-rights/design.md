# Design

Use the acquired Document object and its own descriptor. Number requires positive acquired configured length; Date is the measured Document standard path. Number is (-2,03f171e8-326f-41c6-9fa5-932a0b12cddf), Date (-3,same GUID). Ordinary own attributes require membership in the complete document_attributes list and a unique acquired child descriptor. Unknown lists, nonmembers, absent/ambiguous descriptions and unsupported shapes fail explicitly; matching a name or role UUID is insufficient.

Add resolve_document_attribute_right(snapshot, owner, attribute, right_name), returning the existing opaque ResolvedMetadataRight. Keep resolve_metadata_right signature and Catalog behavior. Its private target distinguishes an owner, exact standard pair or separate attribute rights-object UUID. An ordinary attribute never becomes a fabricated owner-member path. Structural validation precedes privilege policy, which remains in the host. Read of a valid child is NotApplicable; View and owner Read/View are Applicable.

Evaluate complete role results with the existing cache and per-role parent gate. AccessRight gates owner View first. For Document verification only, retained independent=true/default=false explicit child grants and independent=true/default=true missing child grants can pass without owner View. Explicit child refusal beats defaults in supported profiles. The independent/default-enabled/no-parent profile is supported only when the child entry is absent; explicit child records in that combination remain UnsupportedTarget until measured. The existing unsupported Catalog independent/default combination remains unsupported; no cross-kind generalization. No SQL/RLS policy changes.

Evidence: open-bsl document-right-applicability-1019 (144 native rows) and document-right-profiles-1019 (288 rows), 1C8.3.27.2342 native CF/canonical XML/compiled role resources. Preserve previous 492 Catalog/root controls. Other kinds, rights, tabular paths, zero-length Number and Document multi-role compositions are not certified. Per-role aggregation is unchanged.
