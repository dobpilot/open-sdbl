# Design

Resolve each attribute segment using its own typed reference filter in the
ordinary SDBL compilation and rights path. Only the requested attribute is
projected. Intermediate values must be known 1C references. An empty reference
or an absent row propagates SQL NULL. Rights errors remain errors.

Acquire the main data composition schema identifier from the native report
descriptor and resolve it to a template's path in the same Config index.
Distinguish a measured unset property from an unknown format or a dangling
reference. The configured template can have any name.

Extend the service call grammar with text literals, positional text
parameters, and nested scalar text calls. Apply fixed nesting, parameter,
path and argument limits. Evaluate calls locally against the connection's
current gateway state. Backing providers receive only compiled SDBL and
fixed metadata acquisition statements.
