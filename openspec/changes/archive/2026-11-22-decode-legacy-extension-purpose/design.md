# Design

Extend the existing configuration-root decoder. For root version 2 and wrapper version 1, the native 1C 8.3.27.2342 XML exporter confirmed compatibility code `80310` in header field 43 and purpose codes `0`, `1` and `2` in field 44. The measured profiles are marker `52` with 46 elements and marker `68` with 61 elements. Keep the allowed marker, length and compatibility combinations explicit. Both profiles use the existing code-to-enum mapping, and the application continues to consume the typed result from the SDK.

The legacy measurement started with resources read from PostgreSQL ConfigCAS. The original CFE and two local variants, with only field 44 and the corresponding resource hash changed, exported `AddOn`, `Patch` and `Customization`. The current profile was verified with three CFE files generated by the platform in the same compatibility mode.
