# Design

The common statement separator states feed existing table predicate generation for both backends. A disabled Independent separator will become a terminal metadata diagnostic, not an absent predicate and not a retryable missing value. Missing use bindings will retain the existing structural missing-session-parameter diagnostic. States are computed without I/O; only table reads diagnose them. Preparation remains silent because its SQL is discarded.

Native 8.3.27.2342 accepted IndependentlyAndSimultaneously and a false usage query. Its default bound string value was empty and default use false. A distinct-row control will additionally distinguish disabled access from a typed empty filter. Independent explicit false remains a terminal Metadata diagnostic. Existing assertions that contradict native output will be replaced by exact rejection assertions, preserving all surrounding coverage.

## Native evidence

Retained `tests/fixtures/separator-use-0913` receipts prove numeric Independent initial value 0, use No, false rejection and true success. Shared distinct rows prove true/B count 1, false/B and false/C count 2, true/C count 0. The bound SDK state can be absent even though the platform initializes separator-linked parameters; a missing SDK binding requests the host to provide that platform Session value and does not invent one.

Constants scope enumerates metadata fields before their actual usage is known. It retains separator diagnostics internally and exposes them only for chosen constant fields; COUNT(*) without a constant field therefore never requests unrelated separator values. Existing shared-disabled constants aggregation limitations remain unchanged.

Synthetic query fixture sessions that previously disabled Independent to bypass filtering now enable it with an explicit numeric value. The repository maintenance test replayed their compiler SQL snapshots without any changed snapshot lines; native platform receipts are never regenerated by the compiler. Missing-value assertions now explicitly enable use; missing-session identity tests with no bindings assert the use name.

Unmeasured scope: conditional separation, authentication separation, invalid host flag types and unsupported stored separator kinds are not newly implemented. SQL Server live execution is unavailable; its shared compiler tests cover the same state decisions without a second provider path.
