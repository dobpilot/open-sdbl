# Decode native legacy news characteristic metadata

## Why
Original BUH compilation reaches the news characteristic object module, but its five own attribute names are absent because the measured older owner and child profiles are not projected.

## What Changes
Recognize the retained class 32/56 characteristic owner with identity 1/9 and homogeneous 1/5 attribute wrappers with identity 1/7. Preserve measured owner settings and complete ordered qualified declarations. Keep modern characteristic profiles unchanged. No public API or runtime object behavior changes.

## Impact
