# Измеренное строковое равенство, SDK 0.9.36

Исправление ограничено PostgreSQL и оператором `=`. Два строковых операнда сравниваются как `text` после удаления конечных ASCII-пробелов с `COLLATE "C"`. Строка и Number/Boolean/DateTime дают nullable FALSE без преобразования несовместимого значения в строку. Оба операнда разрешаются и компилируются до построения результата; существующие проверки доступа, RLS и разделения остаются в общем пути. Контекстно типизируемый CASE сохраняет существующий путь. Новых зависимостей и публичных Rust API нет.

Нативные скрипты и неизменные эталоны находятся в `tests/fixtures/string-comparison-native-0936`. Красные SDK тесты сохранены в `open-sdbl-0936-red.log`. Шесть собственных тестов проверяют SQL, несовместимые типы, обратные операнды, сохранение контекстного CASE и границы SQL Server/неравенства. Общий BSL/SDK/PostgreSQL контроль родительского проекта дополнительно воспроизводит 24 строковых и 16 типизированных нативных исходов на собственном временном PostgreSQL; это синтетическая физическая схема, не доказательство декодирования Config или входа нативного пользователя.

При регрессионной проверке старые тесты ожидали прежний сырой SQL. До правки родителю переданы точные патчи, он сообщил пользователю причину остановки. Изменения сохраняют источники ограничений, соединения, литералы, счётчики и предикаты других типов. Это не отдельное пользовательское одобрение. Полный обзор корпуса (`corpus-review.json`) показывает 13 изменений SQL из 1726 строк: DEMO 8, UNF 1, BUH 4. Снятие только добавленных rtrim/CAST/C-обёрток восстанавливает прежние строки побайтно. Входные запросы и строки ошибок не изменены. Это SQL goldens, не нативные эталоны.

SQL Server не менялся и вживую не запускался. Неравенство, IN, порядок сортировки и общая типизация составных значений этой работой не расширяются. Выражение над полем может ограничить использование обычного индекса; замер производительности и предположение о сравнении собственных типов mvarchar не подменяют нативное свидетельство и здесь не заявлены.

Рабочее дерево SDK до начала содержало многочисленные авторские изменения и находилось на `feat/extension-purpose-0.9.15`. Поставка выделяется точным патчем относительно снимка до этой работы; чужие изменения не сбрасывались и не включались в новый commit.

Финал: 1153 теста прошли, 0 отказов, 13 штатно пропущены; fmt, Clippy, rustdoc и строгая проверка всего OpenSpec успешны. Изменение заархивировано как `2026-10-21-compile-measured-postgres-string-equality`. Архиватор выдал неблокирующее предупреждение об отсутствии заголовков Why/What Changes в proposal; строгая проверка до и после архивации прошла. Архив не переписывался.
