# Приобретение стандартных реквизитов справочников

Сверка 2026-09-30 на нативной XML 1С 8.3.27.2342 и приобретённых ресурсах Config УНФ. `tests/fixtures/catalog-standard-attributes/unf-native.tsv` содержит 296 совпавших UUID: 290 строковых кодов и 6 числовых. Для всех совпали CodeLength/CodeType/DescriptionLength с позициями 17/18/19 списка Config класса 57. `ВерсииРасширений` дополнительно приобретён read-only SELECT: CodeType Number, CodeLength 9, DescriptionLength 0; исходная XML и compressed Config сохранены. Существующие базы не изменялись.

Публичный API: `ConfigDescriptor::catalog_standard_attributes: Option<CatalogStandardAttributes>`, `CatalogCodeType::{Number,String}` и поля `code_type`, `code_length`, `description_length`. Ноль длины сохраняет настройку метаданных и не определяет доступность BSL-свойства; None — неизвестная форма, а не нулевые длины. Настройки принадлежат только descriptor собственного ресурса; вложенные атрибуты их не наследуют. AcquiredConfiguration удерживает Config-ресурсы; существующий parse_config_descriptor декодирует собственный описатель ресурса. Поэтому MetadataObject не дублирует настройки.

SchemaStorage хранит наличие Code/Description и теги S/N, но нынешний ColumnType отбрасывает квалификаторы длины. MetadataSnapshot::field_id может распознавать объявленный стандартный реквизит, MetadataObject::code_allowed_length основан на live SQL. Ни один из них не заменяет настроек Config. Parent/Owner в SchemaStorage свидетельствуют о физических колонках, но не дают настроенный вид иерархии и список владельцев. Эти свойства не добавлялись и не угадывались. Начальное значение BSL также не выводится из метаданных.

XML УНФ не использовалась для подтверждения свойств buh/demo по общему UUID: предварительная сверка выявила четыре несовпадения длин между конфигурациями. Единственный эталон проверяемого корпуса — XML той же УНФ.

В существующих тестовых фикстурах механически инициализировано новое поле значением None. Старые ожидания и ассерции не изменены. Три новых теста проверяют полный UUID-сопоставленный корпус, числовой код с длиной наименования 0 и отказ угадывать неизвестные настройки.
