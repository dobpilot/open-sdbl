## Повторение измерений

Для проверки номеров создайте отдельную информационную базу штатным `ibcmd infobase create --dbms=PostgreSQL --db-server=localhost --db-name=<новая-база> --db-user=<тестовый-пользователь> --request-db-pwd --locale=ru_RU`; пароль вводится интерактивно. Импортируйте три `Probe*.input.xml` из фикстур в минимальную выгрузку конфигурации через `ibcmd infobase config import`, выполните `config apply --force`, затем `config export`. Сравнивайте итоговые `Probe*.xml` и Config одного UUID, а не двоичный экспорт файла cf.

Для прав добавьте `tests/fixtures/access/native-096/input` в минимальную конфигурацию отдельной файловой базы, исполните `bootstrap.bsl` под полными правами. Исполните `fields.bsl` отдельно под каждым из пяти пользователей; результат должен совпасть с соответствующим `*.platform.txt`, включая canary имени пользователя. Каталог должен содержать созданную bootstrap строку: успешная компиляция запроса без строки не доказывает чтение поля. Нативные выходные `*.Rights.xml` сохраняют результат обратной выгрузки.
